# Pre-redesign archive

Snapshot van alle pagina's, componenten, data en styles vóór de MKB-redesign (september 2026).

De oude site had een expert/coach positionering (teal + terracotta, Playfair Display serif headings).
De nieuwe site richt zich op praktisch MKB (blauw + geel, Poppins + Caveat).

## Inhoud

- `pages-pre-redesign/` — alle .astro pagina's (NL + EN + ES)
- `components-pre-redesign/` — alle Astro-componenten
- `data-pre-redesign/` — site config, navigation, schema, etc.
- `styles-pre-redesign/` — global.css + tailwind.config.mjs

## Herstellen

Om oude content terug te halen, kopieer het relevante bestand terug naar `src/`.
